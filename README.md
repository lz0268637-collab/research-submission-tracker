# 论文投稿管理系统

一款面向科研人员的 Windows 本地论文投稿工作台，用于集中管理论文、期刊、投稿阶段、返修记录、投稿材料包、文献订阅、科研知识与统计分析。

> 当前为公开测试版。核心数据默认保存在您自己的电脑中，不需要部署服务器。

## 主要功能

- 论文档案：新增、编辑和删除论文，管理作者、关键词与目标期刊。
- 投稿进度：记录已投稿、编辑审稿、外审、返修、编辑决定、录用与拒稿等阶段。
- 投稿材料包：保存全文手稿、投稿信、图表、补充材料及不同版本。
- 期刊库：记录研究方向、出版周期、投稿难度、投稿入口及个人备注。
- 文献监控：通过公开学术数据源更新关注期刊的新文章。
- 科研知识库：沉淀投稿经验、写作规范和研究方法。
- 数据分析：统计投稿数、录用率、审稿周期与阶段分布。
- 可选 AI 分析：支持用户自行配置 DeepSeek、豆包及其他 OpenAI 兼容服务。
- 本地备份：一键下载完整备份，并可在更换电脑后恢复。

## 下载与安装

请前往 [Releases](../../releases/latest) 下载最新的 Windows 安装程序：

```text
ResearchSubmissionTracker-Setup-版本号.exe
```

双击安装并保留“创建桌面快捷方式”选项。安装完成后，从桌面打开“论文投稿管理系统”，浏览器会自动进入本地页面。

## 隐私说明

- 安装包不包含开发者的论文、投稿记录、附件、个人备注或 API Key。
- 用户论文与附件默认只保存在本机 `%LOCALAPPDATA%\ResearchSubmissionTracker\data`。
- AI 功能为可选项，启用后请求会发送至用户自行配置的第三方模型服务商。
- 完整备份可能包含未发表论文、附件和 API Key，请勿公开分享。
